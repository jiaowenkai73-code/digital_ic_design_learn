# Day 1 - RTL Development Environment Setup

Today I started learning digital IC front-end design.

## What I completed

- Installed WSL2 on Windows
- Installed Ubuntu in WSL
- Installed Git
- Installed Icarus Verilog
- Installed Verilator
- Installed GTKWave
- Installed GCC/G++
- Installed Make
- Installed VS Code
- Connected VS Code to WSL Ubuntu
- Created the digital design learning directory

## Current Development Environment

Windows
→ WSL2
→ Ubuntu
→ VS Code

Main RTL tools:

- Icarus Verilog: RTL simulation
- Verilator: RTL lint and simulation
- GTKWave: waveform viewing
- Git: version control
- Make: build automation

## What I learned

WSL allows Windows to run a Linux environment.

Ubuntu is the Linux distribution running inside WSL.

VS Code connects to Ubuntu through the WSL extension, allowing me to edit Linux files and execute Linux commands directly from VS Code.
